# LAVS Foundation

Website for LAVS Foundation — a Los Angeles nonprofit presenting concerts
across the city and supporting the young musicians who play them.

Live at **lavsfoundation.org**

## What is here

```
index.html      Home
about.html      About — purpose, programs, board, governance
styles.css      All styling, responsive
images/         Photographs (3 sizes of the hero image)
_headers        Cloudflare Pages caching and security headers
```

Plain static HTML. No build step. Deployed on Cloudflare Pages —
any push to `main` publishes automatically.

## Editing text

Open the file on GitHub, click the pencil icon, make the change,
and commit. The site updates within about a minute.
